# 两三事 · Bản Việt hóa (cá nhân)

Đây là bản Việt hóa **phi thương mại, dùng cá nhân** của extension SillyTavern **两三事 (ST-TwoMoreThings)**.

- Tác giả gốc: **白鳥三津枝** — repo gốc: https://github.com/atonal519/ST-TwoMoreThings
- Mọi quyền của mã nguồn, thiết kế và tài nguyên thuộc về tác giả gốc. Bản này chỉ dịch giao diện và prompt sang tiếng Việt, không thêm tính năng.
- Phiên bản gốc: 0.6.0

## Đã Việt hóa
- Toàn bộ giao diện điện thoại (Tin nhắn, Diễn đàn, Weibo, ainstgram, Album, Lịch, Cài đặt…).
- Prompt gửi cho AI: AI mặc định viết tin nhắn, bài diễn đàn, Weibo, khoảnh khắc bằng **tiếng Việt**; ngôn ngữ khác sẽ kèm bản dịch tiếng Việt.
- Ngày tháng trên màn hình (T2…CN), đơn vị số (k / tr / tỷ).

## Giữ nguyên tiếng Trung (cố ý)
- Tên riêng: 两三事, 千千结, 构画, 柏宝书, 柏宝绘, 智绘姬.
- Các ký hiệu code dùng để đọc kết quả AI: `[tmt|…|…]`, tiền tố nhóm `群:`, người gửi là bạn `我`, các nhãn `[表情：…]`, `[图片：…]`, `[定位：…]`, `[转账：…]`.

## Cài đặt
SillyTavern → Extensions → Install extension → dán link repo này → Install → tải lại trang.

## Lưu ý
- Chỉ sửa `dist/runtime.js`, `embed.js`, `docs/updates-0.6.0.md` và thêm file này.
- Khi tác giả ra bản mới, bản Việt hóa cần dịch lại theo bản mới.
